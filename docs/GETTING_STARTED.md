# 🚀 快速开始

## 环境要求

- Node.js >= 18
- pnpm >= 8
- Windows 10/11

## 安装

### 1. 克隆项目
```bash
git clone <repository-url>
cd toolbox-assistant
```

### 2. 安装 pnpm（如果未安装）
```bash
npm install -g pnpm
```

### 3. 安装依赖
```bash
pnpm install
```

## 开发

### 构建所有包
```bash
pnpm build
```

### 启动应用
```bash
pnpm dev
```

## 使用

### 系统托盘
应用启动后会在系统托盘显示图标，右键点击可以：
- 打开主窗口
- 快速启动工具
- 退出应用

### 全局快捷键
- `Ctrl+Shift+P` - 打开端口管理器
- `Ctrl+Shift+C` - 启动取色器

### 主窗口
点击托盘菜单"打开主窗口"，可以看到所有已安装的工具模块。

## 工具使用

### 端口管理器
1. 通过托盘菜单或快捷键打开
2. 查看当前系统所有端口占用
3. 搜索特定端口或进程
4. 右键结束进程（需要管理员权限）

### 取色器
1. 按 `Ctrl+Shift+C` 启动
2. 鼠标移动到目标位置
3. 点击取色
4. 颜色值自动复制到剪贴板
5. 显示预览窗口 2 秒后自动关闭

## 故障排除

### 应用无法启动
- 检查 Node.js 版本
- 删除 `node_modules` 重新安装
- 检查端口占用

### 快捷键不生效
- 检查是否与其他应用冲突
- 以管理员身份运行

### 取色器无法使用
- 检查屏幕权限
- 重启应用
