# 🖱 关于桌面右键菜单

## ❌ 为什么没有桌面右键菜单？

### 技术限制

Windows 桌面右键菜单（Context Menu）需要注册 **Shell Extension**，这需要：

1. **C++ 或 .NET 开发** - 不能用 JavaScript/TypeScript
2. **COM 组件注册** - 需要修改注册表
3. **代码签名** - 需要数字证书
4. **管理员权限** - 安装和卸载都需要
5. **系统稳定性风险** - Shell Extension 崩溃会影响整个资源管理器

### 与 Electron 集成的问题

- Electron 应用无法直接创建 Shell Extension
- 需要额外开发 C++/C# 组件
- 维护成本高，兼容性问题多
- 用户安装体验差（需要管理员权限）

---

## ✅ 我们提供的替代方案

### 1. 系统托盘菜单（推荐）⭐

**优势**：
- ✅ 快速访问
- ✅ 始终可用
- ✅ 无需管理员权限
- ✅ 稳定可靠

**使用方法**：
1. 在任务栏右下角找到应用图标
2. 右键点击图标
3. 选择需要的工具

**菜单内容**：
- 🏠 打开主窗口
- 🔌 端口管理器
- 🎨 取色器
- ⚙️ 设置
- ❌ 退出

### 2. 全局快捷键（最快）⚡

**优势**：
- ✅ 最快速的访问方式
- ✅ 任意位置可用
- ✅ 无需鼠标操作

**快捷键列表**：
- `Ctrl+Shift+P` - 端口管理器
- `Ctrl+Shift+C` - 取色器

**自定义快捷键**：
- 在设置中可以自定义快捷键
- 避免与其他应用冲突

### 3. 主窗口（完整功能）🏠

**优势**：
- ✅ 查看所有工具
- ✅ 管理工具设置
- ✅ 现代化 UI

**使用方法**：
1. 右键托盘图标 → 打开主窗口
2. 或使用快捷键（可自定义）
3. 浏览所有工具并点击打开

## 🔮 未来可能的方案

### 方案 1: 可选的 Shell Extension 插件

**实现方式**：
- 提供独立的 Shell Extension 安装包
- 用户可选择是否安装
- 与主应用通过 IPC 通信

**优点**：
- 提供桌面右键功能
- 不强制用户安装

**缺点**：
- 需要额外开发 C++ 组件
- 安装需要管理员权限
- 维护成本高

### 方案 2: 文件关联

**实现方式**：
- 注册特定文件类型的右键菜单
- 例如：右键 .log 文件 → 用端口管理器打开

**优点**：
- 相对容易实现
- 针对特定场景

**缺点**：
- 仅限特定文件类型
- 不是通用的桌面右键

### 方案 3: 快速启动栏

**实现方式**：
- 在任务栏添加快速启动图标
- 点击显示工具菜单

**优点**：
- 快速访问
- 无需右键

**缺点**：
- 占用任务栏空间
- 不是真正的右键菜单

## 💡 推荐使用方式

### 日常使用

**最快方式 - 快捷键**：
```
Ctrl+Shift+P  →  端口管理器
Ctrl+Shift+C  →  取色器
```

**便捷方式 - 托盘菜单**：
```
右键托盘图标  →  选择工具
```

**完整方式 - 主窗口**：
```
打开主窗口  →  浏览所有工具
```

## 🎯 最佳实践

### 1. 记住常用快捷键

将最常用的工具快捷键记住：
- 端口管理：`Ctrl+Shift+P`
- 取色器：`Ctrl+Shift+C`

### 2. 固定托盘图标

确保托盘图标始终可见：
1. 右键任务栏
2. 任务栏设置
3. 选择要显示的图标
4. 开启 Toolbox Assistant

### 3. 自定义快捷键

如果默认快捷键冲突：
1. 打开设置
2. 快捷键管理
3. 自定义快捷键
