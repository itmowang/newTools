# ❓ 常见问题

## 安装与启动

### Q: 为什么需要 pnpm？
A: pnpm 提供高效的 Monorepo 支持和更快的安装速度。如果你习惯使用 npm/yarn，可以修改配置，但推荐使用 pnpm。

### Q: 应用启动失败怎么办？
A: 
1. 检查 Node.js 版本（需要 >= 18）
2. 删除 `node_modules` 和 `dist` 文件夹
3. 重新运行 `pnpm install && pnpm build`
4. 查看控制台错误信息

### Q: 如何以管理员身份运行？
A: 右键 Electron 可执行文件 → 以管理员身份运行

## 功能使用

### Q: 快捷键不生效？
A: 
1. 检查是否与其他应用冲突
2. 确认应用正在运行
3. 尝试重启应用
4. 查看控制台是否有快捷键注册失败的提示

### Q: 端口管理器无法结束进程？
A: 结束系统进程需要管理员权限，请以管理员身份运行应用。

### Q: 取色器取色不准确？
A: 
1. 检查屏幕缩放设置
2. 确认没有其他应用覆盖
3. 尝试重启应用

### Q: 如何修改快捷键？
A: 当前版本暂不支持自定义快捷键，将在 V1.2 版本中添加。

## 开发相关

### Q: 如何开发新模块？
A: 参考 [模块开发指南](./MODULE_DEVELOPMENT.md)

### Q: 模块之间如何通信？
A: 通过 PluginManager 的事件系统：
```typescript
pluginManager.emit('custom-event', data);
pluginManager.on('custom-event', handler);
```

### Q: 如何调试模块？
A: 
1. 使用 `console.log` 输出日志
2. 在窗口中打开 DevTools：`window.webContents.openDevTools()`
3. 使用 VS Code 调试 Electron

### Q: TypeScript 编译错误？
A: 
1. 确保所有依赖已安装
2. 运行 `pnpm build` 构建所有包
3. 检查 `tsconfig.json` 配置

## 架构设计

### Q: 为什么选择 Electron 而不是 Tauri？
A: 
- Electron 生态更成熟
- 系统 API 支持更完善
- 开发体验更好
- Tauri 在 Windows 上的某些功能还不够稳定

### Q: 为什么不支持桌面级右键菜单？
A: Windows Shell Extension 需要 C++/.NET 开发，与 Electron 集成复杂。托盘右键 + 全局快捷键已能满足大部分需求。

### Q: 模块可以访问其他模块吗？
A: 不推荐直接访问。模块应该保持独立，通过事件系统通信。

### Q: 如何实现模块热重载？
A: 当前版本不支持，计划在 V2.0 中实现。

## 性能与优化

### Q: 应用占用内存较大？
A: Electron 应用基于 Chromium，基础内存占用约 100-200MB。可以通过以下方式优化：
- 关闭不使用的模块窗口
- 避免同时打开多个工具
- 定期重启应用

### Q: 启动速度慢？
A: 
- 首次启动需要初始化所有模块
- 后续启动会更快
- V2.0 将实现模块懒加载

## 安全与隐私

### Q: 应用会收集数据吗？
A: 不会。所有数据都在本地处理，不会上传到服务器。

### Q: 端口管理器会泄露敏感信息吗？
A: 端口信息仅在本地显示，不会外传。

### Q: 如何确保应用安全？
A: 
- 从官方渠道下载
- 检查代码签名
- 定期更新到最新版本
